# Professional Learning Portfolio

This repository is a professional learning portfolio created for the Professional Practice in Computing subject. It presents evidence of my learning progress in Python programming, data analytics, machine learning, data visualisation, and GitHub version control.

The portfolio includes two practical Python projects and supporting reflection evidence. These artefacts show how I moved from a learning plan to practical skill development through hands-on work.

## Portfolio Objectives

The main objectives of this portfolio are to:

- demonstrate practical Python programming skills
- practise data cleaning and data analysis workflows
- apply basic machine learning classification techniques
- create visual evidence using charts and summary tables
- use GitHub to organise, document, and track project work
- reflect on my professional development progress

## Projects Included

### Project 1: Loan Repayment Classification

This project uses Python and scikit-learn to build and compare several classification models for predicting whether a loan will be paid back.

Key skills demonstrated:

- data loading and inspection
- train-test splitting
- preprocessing numerical and categorical variables
- classification model training
- model comparison using evaluation metrics
- confusion matrix interpretation
- evidence generation through CSV files and charts

Main tools used:

- Python
- pandas
- scikit-learn
- matplotlib

### Project 2: Real Estate Market Analysis and Value Evaluation

This project uses Python to clean and analyse a real estate dataset. It focuses on exploratory data analysis, feature engineering, price comparison, and visualisation.

Key skills demonstrated:

- cleaning real-world text-based data
- extracting numerical values from raw fields
- creating new features such as building age, room type, and price segment
- analysing housing price patterns
- generating summary tables and charts
- interpreting descriptive data analysis results

Main tools used:

- Python
- pandas
- matplotlib

## Professional Development Reflection

Through these projects, I improved my ability to apply Python to practical computing tasks. I also developed a better understanding of how data analysis projects should be structured, documented, and evaluated.

The first project helped me understand the full machine learning workflow, including model comparison and the importance of using suitable metrics for imbalanced classification problems.

The second project helped me practise exploratory data analysis, data cleaning, feature engineering, and visualisation using real-world housing data.

Together, these projects provide evidence that I have developed practical computing skills beyond theoretical learning and quizzes.
