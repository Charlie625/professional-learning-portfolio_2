Loan Repayment Classification Project Summary
===========================================

Dataset shape: (18000, 21)
Target column: loan_paid_back
Dropped columns: ['loan_paid_back', 'id']
Numeric features: ['age', 'annual_income', 'monthly_income', 'debt_to_income_ratio', 'credit_score', 'loan_amount', 'interest_rate', 'loan_term', 'installment', 'num_of_open_accounts', 'total_credit_limit', 'current_balance', 'delinquency_history', 'num_of_delinquencies']
Categorical features: ['gender', 'marital_status', 'education_level', 'employment_status', 'loan_purpose']
Best model selected: Decision Tree

Reason for evaluation method:
The target classes are imbalanced, so accuracy alone may be misleading. For this reason, Macro F1 and Balanced Accuracy were used to compare models more fairly.
