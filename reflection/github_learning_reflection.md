# GitHub Learning Reflection

## Overview

Before completing this portfolio, my understanding of GitHub was mainly at a basic level. I knew that GitHub could be used to store code, but I was not fully confident about repository structure, README files, commits, folders, or how to present project evidence clearly.

Through this portfolio, I practised using GitHub as a professional learning and project documentation tool. I learned that GitHub is not only a place to upload code. It can also show project organisation, technical evidence, learning progress, and professional communication.

## What I Learned

One important skill I learned was how to structure a repository properly. At first, I only thought about uploading separate files. Later, I understood that a professional repository should have a clear structure, with a main README, separate project folders, project-level README files, code files, datasets, output folders, and reflection evidence.

I also learned the importance of README files. A README file helps other people understand what the project is about, what tools were used, how to run the code, and what outputs are generated. Without a README, even correct code can be difficult for others to understand.

Another skill I developed was using commits to track progress. Each commit records a change in the project. This is useful because it shows the development process and provides evidence that the work was built step by step.

## Challenges

One challenge was understanding where each file should be placed. For example, I needed to separate the main portfolio README from the README files inside each project folder. I also needed to avoid uploading unnecessary files such as `.venv`, temporary files, or IDE settings.

Another challenge was learning how to upload folders correctly using the GitHub website. I learned that GitHub does not automatically unzip a zip file after upload, so the correct process is to unzip the folder locally first and then upload the files and folders inside it.

## Professional Value

GitHub is useful for professional practice because it provides evidence of technical skills, organisation, and communication. A well-structured GitHub repository can help demonstrate programming ability, data analysis skills, documentation skills, and reflection on learning.

This learning experience improved my confidence in using GitHub for future study and professional projects. I now understand that a strong portfolio should not only contain code but also explanation, results, and reflection.
