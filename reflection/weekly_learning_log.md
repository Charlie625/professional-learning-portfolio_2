# Weekly Learning Log

## Week 1: Planning the Portfolio

I started by understanding the purpose of the professional learning portfolio. I identified that the portfolio needed to include practical project evidence, GitHub organisation, and reflection. I decided to use two Python-based projects to demonstrate my learning progress.

## Week 2: Project 1 Data Understanding

I worked on the loan repayment classification dataset. I checked the dataset columns, target variable, missing values, and class distribution. This helped me understand the problem before building machine learning models.

## Week 3: Project 1 Model Building

I built several classification models, including a dummy baseline, decision tree, random forest, logistic regression, and KNN. I learned that model comparison should not depend on accuracy only. Macro F1 and Balanced Accuracy were more useful because the target classes were imbalanced.

## Week 4: Project 1 Documentation

I created a README file and output evidence for Project 1. I learned that documentation is important because it explains the purpose of the project, the dataset, the workflow, the tools used, and the meaning of the outputs.

## Week 5: Project 2 Data Cleaning

I worked on the real estate dataset. The raw data contained text-based fields, so I needed to extract numeric values such as area, total price, unit price, room counts, and building year. This helped me understand the importance of data cleaning and feature engineering.

## Week 6: Project 2 Analysis and Visualisation

I generated summary statistics, correlation analysis, city comparisons, room type analysis, orientation analysis, building age analysis, and price segment analysis. I also created charts to make the findings easier to understand.

## Week 7: GitHub Portfolio Organisation

I organised the repository into a professional structure. I created a main README file, separate project folders, project-level README files, output folders, and reflection files. This helped me understand how GitHub can be used as a professional portfolio platform.

## Week 8: Final Reflection

I reviewed the final portfolio and reflected on my learning progress. I improved my confidence in Python, data analysis, machine learning, GitHub, and professional documentation. I also learned that a strong portfolio should show both technical outputs and reflective learning.
