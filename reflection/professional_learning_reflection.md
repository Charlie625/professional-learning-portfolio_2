# Professional Learning Reflection

## Overview
This professional learning portfolio helped me connect technical learning with practical project work. Instead of only learning Python concepts separately, I used Python to complete two applied projects: a loan repayment classification project and a real estate market analysis project.

These projects allowed me to practise programming, data preparation, analysis, visualisation, machine learning, debugging, and documentation. They also helped me understand how professional computing work should be organised and presented.

## Learning Progress

At the beginning, I was less confident in building a complete project from start to finish. I could understand some individual Python commands, but I needed more practice in connecting them into a full workflow.

Through Project 1, I learned how a machine learning classification project is structured. I practised loading a dataset, identifying the target variable, separating features and labels, preprocessing numeric and categorical data, training several models, and comparing performance using multiple metrics. I also learned why accuracy alone can be misleading when the dataset is imbalanced.

Through Project 2, I learned how to complete an exploratory data analysis project. I practised cleaning raw data, extracting numeric values from text, creating new variables, grouping data, calculating summary statistics, and creating charts. This project helped me understand that data analysis requires both technical processing and interpretation.

## Skills Developed

The main skills I developed include:

- Python programming
- pandas data cleaning and analysis
- matplotlib visualisation
- scikit-learn machine learning pipelines
- model evaluation and comparison
- CSV and chart output generation
- GitHub repository organisation
- README writing and project documentation
- reflection on learning outcomes

## Challenges and Problem Solving

A major challenge was debugging. Sometimes the code ran but produced warnings or unexpected outputs. I learned to read the terminal output carefully, identify whether it was a real error or only a warning, and then adjust the code if needed.

Another challenge was making the projects look professional. A working script is not enough for a portfolio. The project also needs a clear README, a logical folder structure, meaningful output files, and a reflection explaining what was learned.

## Future Improvement

In the future, I want to improve my ability to write cleaner code and explain technical results more clearly. I also want to become more confident in using GitHub version control, especially committing changes regularly and writing meaningful commit messages.

Overall, this portfolio shows my progress in practical computing skills. It demonstrates that I can complete small but realistic data-related projects and present them in a structured professional format.
